Theseus is an open-source CLI that treats your legacy web app as the answer key. Kane CLI runs the same plain-English flows on both apps in real Chrome, diffs extracted values and errors, and loops your coding agent until the full suite passes a regression check.

The Bottleneck

Coding agents made rewrites cheap. Verification is what broke.

Teams migrating jQuery, PHP, or legacy React apps hit the same three failure modes.

01 / REVIEW FATIGUE

Senior devs babysit AI diffs

Agents open PRs faster than humans can verify them. Reading diffs tells you what changed in code, not whether checkout totals still round identically.

02 / GREEN-CHECK THEATER

"Done and tested" skips the browser

Static checks and generated unit tests pass while tax order, promo stacking, or minimum-order rules silently drift in real Chrome.

03 / HYDRA REGRESSIONS

Fixing one bug breaks another

Patching one flow often breaks a previously passing flow. Theseus enforces a full regression pass before certifying equivalence.

Closed Loop

Your legacy app is the answer key.

No hand-written assertions and no pixel-diffing that breaks when you modernize the UI.

STEP 01

Baseline once

theseus baseline runs plain-English flows on the legacy URL via kane-cli --agent --headless and caches golden store as values.

STEP 02

Diff real behavior

theseus verify compares extracted values, flow status, console errors, and HTTP 4xx/5xx failures against the cached baseline.

STEP 03

Patch & re-verify

theseus converge sends exact drifts + Kane .evidence logs to claude -p (or any --agent-cmd) with stuck-loop guards.

STEP 04

Sign the proof

After a clean full regression pass, Theseus emits a SHA-256 signed report.html with side-by-side Kane screenshots and git diffs.

CLI Reference

Five commands. Exit codes built for CI.

Exit 0 equivalent, 1 drift or stuck, 2 setup or auth error. Works with any coding agent via --agent-cmd.

theseus init Scaffold theseus.yaml with plain-English flows and store as keys.
theseus baseline Run flows once on the legacy URL and cache golden values + Kane evidence in .theseus/baseline/.
theseus verify Diff modern URL against cached baseline. Gate PRs with exit 0 or 1.
theseus converge Closed loop: verify, prompt coding agent, re-verify failing flows, run full regression pass, emit SHA-256 HTML certificate.
theseus demo Boot bundled LegacyMart + ModernMart locally and run converge end to end in one command.
